# 极光动态壁纸（DeepSeek Harness 插件）

在 DeepSeek Harness 网页界面背后画一层缓慢流动的生成式极光，也可以换成本机的图片或视频当壁纸。
所有设置都在侧栏底部的小面板里调，不需要改配置文件，也不需要重启。

## 功能

- **生成式极光** —— 6 团柔光在界面背后缓慢漂移、呼吸；不依赖任何图片素材，页面里用 canvas 实时绘制。
- **13 套配色** —— 极光、晚霞、黄昏、蜜桃、樱粉、紫罗兰、森林、薄荷、深海、冰川、霓虹、火山、月白。
  每套 6 个颜色，对应 6 团光斑。
- **自定义颜色** —— 6 个取色器，随时切到自己的配色。
- **呼吸 / 流动** —— 两个滑块分别控制亮度与半径的起伏、光斑漂移速度（0% 完全静止）。
- **浓度** —— 极光相对界面表面的强度。
- **自定义壁纸** —— 选本地图片（JPG / PNG / WebP / GIF）或视频（MP4 / WebM），自动铺满整个窗口，
  静音循环播放；此时动态极光暂停。
- **亮度 / 蒙层** —— 单独调自定义壁纸本身的亮度和盖在上面的遮罩，亮照片和暗视频都能看清。
- **面板可拖动、可缩放** —— 位置和大小会记住。
- **跟随主题** —— 暗色主题是深空极光，亮色主题是浅色晨光。
- **默认保证可读性** —— 只把画布和侧栏做成半透明，卡片、弹窗、菜单、设置页保持原生不透明。

## 安装

```sh
dsh plugin --profile <你的 profile> add dsh-aurora-wallpaper
```

也可以在插件市场里一键安装。装完刷新页面（或重启 DSH）。

## 使用

1. 点侧栏底部的 **壁纸** 按钮（设置旁边）。
2. **动态壁纸** 页签：选配色或自定义颜色，再调呼吸、流动、浓度。
3. **自定义壁纸** 页签：选一张图片或一段视频，再调亮度和蒙层。
4. 切回 **动态壁纸** 页签即恢复极光；自定义的文件仍保存在本机，随时可以切回去。

## 隐私

自定义图片/视频只从本机读取，存在当前源的 IndexedDB 里，不会上传，也不会走网络。

## 环境要求

- DeepSeek Harness `0.2.1-rc.3` 或更新版本，且使用 Web 界面。
- Chromium 内核的客户端（Web 界面就是）。
